如何创建令牌、上传和删除

创建访问令牌

  1. 用 zazaIl 登录 GitHub，打开 Settings → Developer settings → Personal access tokens。
  2. 建议选择 Fine-grained token。Repository access 只勾选 lace-pattern-search。
  3. Permissions 里把 Contents 设为 Read and write，然后生成令牌。
  4. 把令牌粘贴到上面，点击「验证连接」。它只写在这台浏览器的本地存储里，不会进入网页代码。

上传样品

  1. 连接成功后，把 JPG 或 PNG 拖进上传区，也可以一次选多张。
  2. 品名编号默认取文件名，上传前可以修改。
  3. 点击「写入样品库」。页面会先计算纹理，再把图片和索引一起保存。
  4. 一次最多 40 张。五百张样品请分批写入。公开检索页通常一两分钟后能看到新图。

查看、改编号、删除

  1. 下方列表就是当前云端样品，可用编号筛选。
  2. 改完编号后点击「保存编号修改」。
  3. 点击「删除」并确认后，图片和索引会一起从云端移除。
  4. 如果以后更新了比对算法，点击「重新计算全部索引」。

上传新样品

支持 JPG、PNG。上传前会自动缩小，并把透明背景补成白色。自动识别样品卡文字区，缩略图仍保留完整样品。
